01 Featured architectures

Core systems and active research implementations.

Four systems that define the current engineering surface — each with its own domain, stack, and verification story.

01 ggn.kellersystems.dev

Global Ghost Net

Serverless peer-to-peer WAN mesh routing daemon written in pure Rust. Nodes establish direct authenticated mesh tunnels with uniform packet padding and randomized timing jitter to defeat deep packet inspection.

Key primitives Hybrid ML-KEM-512 (Kyber) + X25519 ECDH for forward-secret post-quantum encryption.
Fault resilience Reed-Solomon RS(2,1) erasure coding splits payloads across disparate relay paths.
Stack Rust • Tokio • UDP

02 muon.kellersystems.dev

MuonScope Tomography

Cosmic-ray muon scattering and absorption tomography pipeline. Harnesses natural relativistic cosmic-ray muons to non-destructively invert interior 3D density distributions inside opaque, heavily shielded structures without artificial radiation sources.

Reconstruction core Point of Closest Approach (PoCA) 3D ray-tracing solver for angular trajectory deflection.
Detector modeling Multi-layer silicon strip digital twin with coincidence window timing and FPGA trigger logic.
Stack Python • TypeScript • NumPy
Ecosystem links
Landing page HoloForge GitHub
03 plane.kellersystems.dev

PlaneOS

High-assurance flight control prototype exploring deterministic scheduling and envelope protection in Rust. Implements static memory guarantees to eliminate non-deterministic allocation jitter and GC pause times during critical control loops.

Safety kernel Triple Modular Redundant (TMR) sensor voters and boundary assertion invariants.
Design standards DO-178C DAL A formal methods research guidelines with static verification.
Stack Rust (no_std compatible)
Ecosystem links
Landing page KELLER-OS OP-Roboter
04 citadel.kellersystems.dev

SybilGuard

Cryptographic identity and proof-of-personhood protocol. Evaluates trust topology using zero-knowledge proofs to confirm network graph connectivity without disclosing the user's graph neighborhood, biometric secrets, or transactional footprint.

Privacy mechanics zk-SNARK circuits for non-interactive graph verification; homomorphic operations for private state scoring.
Formal solvers Paired with SymEx EVM for SMT-solver symbolic execution.
Stack Rust • Bellman / Arkworks
